# Phase 3：疊塔、遺物與構築驗收

本目錄提供獨立合成地形，不寫回 Frontier、塔／兵種 Resource 或舊專案。F5 仍是原三 ACT 正式關卡。結果和截圖放在 `.godot/test-results/relics/`；`.godot/phase3-*.log` 是 Phase 3 歷史驗收，後續回歸使用各次獨立 log。

## 人工驗收

在 Godot 開啟 `tests/relics/playground.tscn`，按 F6。補牌使用 **B** 或右上「補齊缺少的塔牌」按鈕；不要按 F8，該鍵是 Godot 編輯器的停止執行快捷鍵。只檢查目前手牌，六個塔種缺哪種就補一張；同種不同 TilePreset 也算已有，原牌及重複牌都保留。六種齊全時不加牌。按住 B 不連續補牌，暫停時不能補牌。

1. 場上預先建好六塔，手中各有一張同種牌，金幣 100。拖迫擊砲牌到原迫擊砲，確認綠色模型、`Lv.1 → Lv.2`、只有攻擊格線而沒有建造道路。放開後只消耗一張牌，原塔位置／方向不變。Hover 可看等級。
2. B 或右上「補齊缺少的塔牌」按鈕補齊缺少的塔牌；同種牌可升到 Lv.3，再拖同種牌應看到封頂提示，牌保留。選「成為主角」並按取得，即可繼續疊哨塔至 Lv.4 以上。
3. 點入口開始波次。F9 會清完本波；飛行中砲彈先落地，再顯示三張遺物卡。選一張後進入下一 ACT 準備。正式關卡此時會先選擴張入口；本驗收場景保持雙入口，方便比較。
4. 左上「本局遺物」可展開收藏；選擇遺物時仍可使用頂部暫停。暫停不能取得遺物，繼續後保留選擇階段；重開清除全部本局狀態。
5. 右上「自由增添／移除遺物（測試）」面板可隨時收合。點目前遺物名稱展開面板內的 21 項清單，可用滾輪捲動，點項目選取；閱讀效果後按「立即增添所選遺物」或「移除所選遺物一份」。選單同步顯示持有數／上限與結果；專屬最多一件，通用可逐份增減至各自上限，移除後可再次取得，暫停禁止增減。撤回效果會更新現有塔、重刷價格，停止巡航／齊射並收回增援的第三名友軍，釋放其接戰；移除「成為主角」保留已升等級，但恢復升級上限。已發放金幣、已造成傷害／命中狀態及在途攻擊快照不倒轉。F7 一次取得全部 17 件專屬，用於協同觀察；正式遊戲沒有這些快捷鍵或測試選單。
6. 逐組檢查：冰霜的淡藍射線與狀態圖示；砲彈固定落點、慢砲 Miss、每三發較大紅色砲彈及單次爆炸；飛行艇往返巡航時底座／支架固定，兩側砲管與艇身一起移動，右舷三連射的砲口及特效跟隨艇身，移除「出發」後復位；弩箭沿線貫穿、敵人沿路倒退；哨塔金色處決；兵營第三人、遠攻光跡與死亡重生。
7. B 或右上按鈕可補牌、商店可正常買牌／重刷；放置三種交通設施、Hover 入口菱形驚嘆號才展開情報，移至兵種列仍可篩選／開波，離開整個提示後收起，確認流量預測與配額仍工作。最後 ACT 選完遺物後停止開波。

測試關卡每 ACT 一波，混合三個既有兵種，單位 HP 1200，只為延長觀察時間。`-- --smoke` 會自動拍準備、戰鬥、遺物選擇三張圖後退出。Boss／flying 的標籤驗證使用測試內臨時 Troop，不新增正式敵人資源。

## 自動化

```powershell
godot --headless --path . res://tests/relics/stacking.tscn
godot --headless --path . res://tests/relics/rewards.tscn
godot --headless --path . res://tests/relics/mechanisms.tscn
godot --path . res://tests/relics/input.tscn
godot --path . res://tests/relics/playground.tscn -- --smoke
```

- `stacking`：同種／異種、不同配置、消耗與價格、原地不改方向／道路／graph 通知、冷卻、受傷比例、Lv.3、Lv.100 與溢位的原子拒絕、兵營人數與生命。
- `rewards`：21 件資料驗證、專屬唯一、通用保底、三選一不重複、現有塔類型的弱關聯、sqrt 權重、既有／新建塔、Gold／重刷費、UI 重複點擊、獨立新局。
- `mechanisms`：17 專屬的實際戰鬥；包括多來源加法／移除、small／flying／boss、緩速堆疊／到期、巡航與四向右舷、齊射、處決優先／空耗、射程預覽、隔離判定含兵營、真實貫穿／每敵單發一次、轉角擊退、第三人與遠攻／接戰／重生，以及砲彈延時、Miss、空中高度、特殊發數、友塔摧毀、道路與行程不變、來源／目標死亡後仍命中、單次爆炸。
- `input`：實際 SubViewport 滑鼠拖牌、升級模型與文字、道路不出現、消耗、ACT 鎖定、暫停選擇、真正點擊遺物卡、收藏、卸載和新局；另以滑鼠實際展開 21 項清單、滾輪捲至首尾、點選／增添／移除／再次取得，驗證唯一與通用數量、暫停阻擋及 800×600 版面。渲染測試顯式送入 viewport mouse-enter，避免隱藏測試視窗的初始失焦被誤判成玩家離開。
- 既有 `level_flow`、`act_spawn_expansion`、`road_flow_preview`、`traffic/integration` 已納入「遺物先於擴張／下一波」；`tower_restoration` 改驗證迫擊砲落地傷害；`card_drag_placement` 的非法占格案例改為已封頂塔。

## 交付範圍

3A–3E 均有實作與驗證入口，停在人工驗收。倍率仍是 MVP，沒有做長局平衡或新增專屬遺物。專屬圖示沿用其塔種圖示，通用遺物使用新的簡單 SVG。Windows Compatibility 已渲染；Web 匯出／瀏覽器、長時間壓測及人工美術／手感核准需另行驗收，不能把 headless 結果當成這些項目已通過。

詳細規則與數值見 [Phase 3 系統](../../docs/phase3.md)。Phase 3 歷史 PASS／FAIL／NOT RUN 與環境見 `.godot/test-results/relics/acceptance.md`；本次 Offboarding 及歷史未重跑項目見 [HANDOFF](../../docs/HANDOFF.md)。
