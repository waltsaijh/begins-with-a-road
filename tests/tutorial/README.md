# 五步教學關卡

F5 → 開始遊戲 → 第一關「第一條防線」→ 下一步 → 開始作戰。教學為 1 ACT、3 波；通關後才能進 Frontier，Bridge 另需通關 Frontier。既有後續關卡通關紀錄也不能跳過 tutorial 前置。

1. 左鍵由卡牌以外平移、滾輪縮放、右鍵繞中心旋轉，各實際操作一次。
2. 固定手牌為哨塔／迫擊砲／弩砲，皆附教學專用跨橋地塊。第一張依金色 hologram 原方向放在橫路；第二張按 R 或單擊右鍵轉 90°，放在縱路；前兩次各形成繞過塔的實體道路。第三張可任意合法放置，不限制落點或方向。
3. 按入口的「開始下一波」標題，等待 1.5 秒，觀察四名步兵。
4. 清波後商店保證一張哨塔，購買並放到原哨塔上升級；錯誤落點不消耗卡片。此時不能跳過升級重刷。
5. 商店重開，玩家按刷新牌並支付正常費用，保證出現交叉火力。買下後進入自由實戰，解除指定建造／購買／刷新限制，可放下新牌並手動開第 2、3 波。第三波與最後 ACT 遺物選擇完成後才保存通關 ID，再返回主畫面。

首波獎勵 20 金幣足夠完成哨塔、一次刷新與交叉火力購買；後兩波各 10 金幣，沒有額外升級費。引導階段只允許目前要求的購買，避免誤花金幣卡關；自由實戰恢復正常商店。中途返回或重新開始會從鏡頭操作重來。初始卡牌與順序可在 `assets/data/tutorial/intro.tres` 的 Starting Cards 編輯，詳見 [資料說明](../../assets/data/tutorial/README.md)。

```powershell
godot --headless --path . res://tests/tutorial/intro.tscn
godot --path . res://tests/tutorial/intro.tscn
```

`intro` 使用真實相機輸入、點選卡牌、R 旋轉、點地圖、點開波、點購買／刷新，驗證五步順序、非法放置不扣牌、前兩次道路繞行、第三次多個合法選擇、升級不改導航、金幣與強制商品、購買後不通關／可自由放新塔、完整三波及最後 ACT 獎勵才保存、暫停隱藏、重玩重置，以及修改初始卡順序後的提示與升級 hologram。清波階段使用測試工具移除敵人，不作長時間戰鬥／平衡驗收。另拍攝中英文、1280×800／800×600 的代表畫面，輸出至 `.godot/test-results/tutorial/`。
