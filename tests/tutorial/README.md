# 五步教學關卡

F5 → 開始遊戲 → 第一關「第一條防線」→ 下一步 → 開始作戰。教學為 1 ACT、3 波；通關後才能進 Frontier，Bridge 另需通關 Frontier。既有後續關卡通關紀錄也不能跳過 tutorial 前置。

1. 不發手牌，左鍵平移、滾輪縮放、右鍵繞中心旋轉，各實際操作一次。
2. 完成視角練習後，以依序飛入左下角的動畫發出哨塔／迫擊砲／弩砲三張牌。第一張依閃爍的半透明 hologram 原方向放在橫路；第二張按 R 或單擊右鍵轉到指示方向（目前 180°），放進道路轉角；前兩次各形成繞過塔的實體道路。第三張可任意合法放置。
3. 按入口的「開始下一波」標題，等待 1.5 秒，觀察四名步兵。
4. 清波後商店保證一張哨塔，玩家自行點開商店、購買並放到原哨塔上升級；錯誤落點不消耗卡片。此時不能跳過升級重刷。
5. 玩家自行重開商店，按刷新牌並支付正常費用，保證出現交叉火力。買下後進入自由實戰，解除限制，可放下新牌並手動開第 2、3 波。第三波結束直接保存通關 ID，不選遺物；中央結算內容中包含通關文字與「重新開始這關／繼續下一關」，後者直接開啟第二關「邊境前哨」的選擇戰場頁。

需要選牌、開商店、購買、刷新或開波時，以大框平滑收縮至目標附近，停留後輕微脈動，其他畫面由挖孔遮罩壓暗；完成該操作後淡出。遮罩不攔截輸入，暫停／設定／載入／結算期間隱藏所有教學提示。

首波獎勵 20 金幣足夠完成哨塔、一次刷新與交叉火力購買；後兩波各 10 金幣，沒有額外升級費。引導階段只允許目前要求的購買，避免誤花金幣卡關；自由實戰恢復正常商店。中途返回或重新開始會從鏡頭操作重來。初始卡牌與順序可在 `assets/data/tutorial/intro.tres` 的 Starting Cards 編輯，詳見 [資料說明](../../assets/data/tutorial/README.md)。

```powershell
godot --headless --path . res://tests/tutorial/intro.tscn
godot --path . res://tests/tutorial/intro.tscn
godot --path . --script res://tests/tutorial/completion_flow.gd
godot --headless --path . --script res://tests/tutorial/focus_geometry.gd
```

`intro` 以真實相機、卡牌、旋轉與商店輸入驗證五步順序、延後發牌、hologram 半透明脈動、焦點收縮／完成淡出、不自動開店、道路繞行、合法放置／升級、自由實戰及第三波直接結算，並檢查重玩與初始牌重排。清波階段使用測試工具移除敵人，不作長時間戰鬥／平衡驗收。`completion_flow` 專測兩個勝利按鈕的實際點擊、場景釋放、重新開始無手牌及繼續後單次交接至第二關選圖。中英文、1280×800／800×600 截圖輸出至 `.godot/test-results/tutorial/`。

`focus_geometry` 檢查不同 CanvasLayer 位移、縮放、旋轉與卡面搖動下，焦點四角仍對齊實際卡面；暗罩與同一旋轉四邊形挖孔合起來覆蓋整個 viewport，外側區域不重複覆蓋。`intro` 另檢查中英文預先換行的行數，不允許句中再被自動折成零碎短行；`completion_flow` 驗證兩個操作都在勝利結算 Panel 內。

勝利慶祝：`intro` 驗證左右 24 片、同次結算不重播、碎片避開內容區並於 1.4 秒內清理，截圖為 `05_victory_burst.png`。`completion_flow` 以真實音訊裝置等待約 3.918 秒勝利音效自然結束，確認再接回 BGM，亦驗證提前重玩的場景清理。`tests/menus/game_audio.gd` 測音效單次／取消／接歌訊號，`tests/balance/defeat_input.tscn` 確認失敗沒有慶祝或勝利音效。
