# Enemy Art Slice A

九個同名 `.blend` 是可單獨編輯的來源。模型以 Blender 5.2.3 LTS 透過 Blender MCP 製作，Godot 4.7.2 Compatibility 使用同一組動作。可在 Godot 開啟 [九兵展示場景](../../../../tests/enemies/enemy_art_gallery.tscn) 並按 F6。

## 尺度與動作

一單位為一格道路。Blender +Y 向前、Z 向上，經 glTF 換軸後為 Godot −Z 向前、Y 向上。根節點固定於足底中心，縮放 1。尺寸是整個循環中各可動件包圍盒的聯集，保守包覆舉起的道具與翼尖。飛翼獸的高度欄只計模型；戰鬥路點另加既有 1.2 格飛行高度。

## 材質與交付

沿用 Art Slice G 的鐵、木、帆布及切角幾何，服色、皮毛和暗紅晶體的 sRGB 色票在 [build.py](build.py) 的 COLORS 中。材質為不透明純色、metallic 0、roughness .87，盔頂、盾面與動物軀幹採平滑法線，布料切邊與硬件保留稜線。每個可動群組合併其固定幾何，關節保留本地原點。所有 GLB 均含單一模型根、具名零件、材質與 Walk-loop。血法師另有 Cast，爆破手另有 Throw。

1. 在專案的專用空白 Blender 工作階段，透過 MCP 執行 `runpy.run_path(建模腳本絕對路徑, run_name="__main__")`。腳本引用相鄰 art_slice_g 的 style.py，逐一輸出本目錄來源與 [九份 GLB](../../../../assets/models/enemies/slice_a/)。來源存於 Godot 忽略的製作目錄。
2. 以 Godot `--headless --editor --path . --import` 匯入，Walk-loop 會成為循環的 Walk。若手動編輯單一 .blend，可直接從該場景重新匯出同名 GLB，保留同一動畫名稱。
3. 執行 `--headless --path . --script res://tools/assets/bake_enemy_slice_a.gd`。每兵種產生一份壓縮的 `_gpu.res`，含單 surface 網格、96 Hz 剛體樣本、GPU 查表資料與 CPU 拾取用的部件界限。材質與塔共用光照、粗糙度及雲影程式。陣列只於離線烘焙時建立。
4. 各兵種 Troop 的 Model 指向 GLB，GPU Model 指向同名烘焙檔。圖鑑讀 Model，正式敵群從 EnemyWave 的既有路點與 EnemyPose 取得世界座標及朝向，再依 enemy_id 起始相位、移動混合及遊戲時鐘提交批次。GPU 與點擊拾取使用相同的部件變換插值。飛行單位停止前進時保留慢速翼拍，暫停時定格。

## 技能與鼠群

- 血法師實際回復生命時立即結算治療，駐足 0.55 遊戲秒，舉杖、晶體亮起、收杖。範圍內無人受傷時照常走路。
- 爆破手沿用兩秒前搖，轉身朝目標塔，從腰間取出陶罐。陶罐在 Throw 的第 31／48 幀離手，以弧線落向同一座塔。能力照原時機結算，失去合法目標會取消。
- 兩段動作以能力剩餘時間取樣。駐足只扣除路點推進時間，結束後沿原路點續行。技能期間以 GLB 的實際姿勢拾取，步行恢復使用 GPU 批次。
- 每個 rats 實體顯示一隻鼠，有自己的生命、受擊與選取，由原排程將同組五員分到相同路線。尺寸依實例相位在基準的 ±9% 內變化。正式 HUD 沿用單位資訊顯示生命。

## 驗收入口

- `tests/enemies/enemy_art_gallery.tscn` 可同時比較九種兵。加上 `-- --capture` 可保存展示截圖。
- `--fixed-fps 60 --script res://tests/enemies/enemy_art_wave.gd` 於正式關卡場景載入獨立測試波次，檢查九種實體的生成、飛行高度、朝向、移動／動畫時鐘、暫停及死亡清場。渲染模式另存戰場與最遠四向截圖到 `.godot/test-results/enemies/slice_a/`。
- `--script res://tests/enemies/enemy_gpu_render.gd` 使用 Compatibility 比對九種兵各三個姿勢的 GLB 與 GPU 像素。混合批次與既有著色器相容性由 `enemy_gpu_models.gd` 與 `solid_material.gd` 檢查。正式點選、受傷、護盾與死亡資訊使用 `tests/levels/unit_inspection.gd`。
- 九份 Blender 來源已逐一重新載入，所有零件在循環起點與終點的矩陣一致。Windows 實機驗收涵蓋本切片；Web、完整十五波與長時間效能仍待另測。
