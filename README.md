# Begins With a Road

一款從雲海上的一條道路開始，透過卡牌逐步擴建戰場的 3D 塔防遊戲。每張建造卡同時帶來防禦塔與道路配置；你安排的不只是火力，也是在改變敵人接下來可以走的路。

## 核心遊戲體驗

地圖選單會自動收錄 `assets/data/levels/` 內的關卡；前置關卡全部通關後解鎖，通關紀錄會保留至下次啟動。製作新關卡只需新增 Level `.tres` 並指定地形與波次，選單預覽會自動載入；欄位與前置 ID 範例見[關卡說明](assets/data/levels/README.md)。

從簡單的橋面出發，挑選手牌、旋轉配置，把道路與防禦塔一起接進現有地圖。道路必須保持入口到終點暢通，因此每次建造都要考慮空間、繞路與火力覆蓋，不能靠完全封路阻止敵人。

不同兵種對道路有不同偏好：步兵在候選路線間平均分配，快腳兵傾向避開威脅，重裝兵則偏好高威脅路線。同一張地圖可能因此出現不同的進攻路徑；建造的價值也取決於下一波會遇到誰。

準備與戰鬥交替進行。你可以不限時安排防線，準備好後手動開始下一波。波次結束後，在商店購買或重刷建造卡，繼續延伸道路。前四個 ACT 完成後各三選一取得本局遺物；第五個 ACT 清完則勝利。Frontier 保留原入口，新增道路仍可改變敵人的分流與火力覆蓋。
自訂關卡可依各 ACT 設定，在遺物後選擴張方向與新增入口。

## 遊戲目標與目前進度

玩家的目標是利用有限的卡牌、空間與金幣建立防線，阻止敵人抵達終點，應對關卡各個 ACT 的進攻。設計重點是讓「鋪路」與「建塔」成為同一個決策，並讓不同兵種、道路形狀與本局遺物持續改變配置的取捨。

首次遊玩從三波的「第一條防線」教學開始，完成後解鎖邊境前哨。目前可遊玩五個 ACT、每個三波的完整首輪原型，包含建造／疊塔、商店、九種普通敵人、四次遺物選擇與最終攻城巨獸。防線有 20 點生命；一般漏敵扣 1，巨獸抵達即敗北，清完第 15 波及在途攻擊則勝利。結果畫面可重新開始。初始三張塔牌與 9 金幣，第一波前即可購買；每波不限時準備，擊殺不額外給錢。Frontier 不自動增加入口，獨立測試仍保留擴張工具。這是第一輪量測過的數值，尚待真人遊玩驗收，保存通關與敵軍圖鑑解鎖紀錄，沒有進行中存檔或局外成長。

## 自己畫塔體與道路

開啟 [Tower Tile Editor](tests/tower_tile_editor/editor.tscn) 按 **F6**，即可選六種塔、畫連通的多格塔體與道路、調整錨點／接口／方向，保存多份有不同抽取權重的配置。「儲存 → 加入手牌試玩」立即返回直線關卡；所有塔體格都會阻擋敵人，但仍是一座塔。測試面板可選配置、補牌、重抽、清手牌及重開，原商店與手動戰鬥仍可使用。

可隱藏／排除內建配置，將跨塔種的配置選擇保存成具名組合，從試玩右上選單切換並重開比較；實際抽牌與放置只允許目前組合的成員。「基礎版」的五塔各四份配置與既有兵營已接入 Frontier 的正式抽牌。塔體按真實占格呈現；目前新六塔美術的 Lv1–3 共用 Lv1 幾何，迫擊砲／交叉火力以整體砲座為中心，空艇舷炮兩側各覆蓋 2×3；預覽清楚分開塔體、道路與連續射程色面。傷害、攻速、價格與成長曲線保留。唯讀 [外觀對照場景](tests/tower_visuals/gallery.tscn) 可用 1–6／R／A 切換塔種、旋轉與射程，詳見 [塔體與預覽](docs/tower_visuals_and_preview.md)。完整操作、直接執行命令、Windows Editor DLL 限制與人工驗收情境見 [使用說明](docs/tower_tile_editor.md)。

## 複合地塊建造實驗

新塔牌附帶的道路遇到已建塔時會自動裁切，保留原塔；剩餘道路仍須讓所有入口通往基地。並排且相通的道路現在呈現連續寬路，塔旁路面自然終止，死路與孤立道路以灰色區分。可用 [道路對照場景](tests/road_refinement/gallery.tscn) 按 F6 查看十個案例，或在原 Tower Tile Editor 試玩；詳見 [規則與人工驗收](docs/road_visual_and_placement_refinement.md)。

道路外側新增有斜面與暗部的路肩，保留連續的凹陷路面；橋頭會正確銜接，流量筆觸也會沿寬路中央轉彎／分岔。最新 [凹槽與流線驗收場景](tests/road_refinement/depth_flow.tscn) 可用1–9／0、R與Space查看十種配置及動畫。

另有獨立 [Construction Playground](tests/construction/playground.tscn)：在 Godot 開啟該場景按 **F6**，可比較舊版即時放置、五種複合形狀及批次預擺。批次可以暫時斷路，先移動、旋轉、排序或撤銷，再確認整組配置；開始戰鬥前必須全路連通。弩砲長直線射程與交叉火力路口傷害提供兩種小幅幾何獎勵。

實驗明示提供六張卡、60 Gold、補牌／換形工具與無敗北，仍可使用原商店、開波及戰鬥。F5 的 Frontier 不受模式切換影響。操作、限制及對照結果見 [原型說明](docs/construction_prototype.md)；目前已完成自動驗證，待真人操作與美感驗收。

## 開始遊玩

第一關為「第一條防線」（1 ACT、3 波），通關後解鎖後續關卡：依序練習鏡頭操作、按 hologram 放置與旋轉卡牌、開始波次、購買同種哨塔升級，再刷新商店購入交叉火力。初始手牌預設為哨塔、迫擊砲與弩砲，第三張可自由放置；購買後進入自由實戰，打完第 3 波與最後 ACT 獎勵才通關。初始卡牌可由 [教學資料](assets/data/tutorial/README.md) 編輯。

使用 Godot 4.7.2 開啟 `project.godot`，按 **F5** 先顯示共用顯示準備畫面，完成後開啟開始選單，點「開始遊戲」選擇戰場，按「下一步」進入同頁的本局設定，再按「開始作戰」進入正式關卡；也能先開設定調整語言、抗鋸齒、靜音與整體／BGM／戰鬥音效音量。選圖頁提供「邊境前哨」與「第一條防線」教學，可預覽實際道路與入口、終點配置。本局設定先提供難度、起始手牌與額外事件的暫定選項，目前僅供流程預覽，尚未影響戰局；返回或 Esc 可逐步回上一步並保留選擇。專案使用 Compatibility 渲染器，目標包含 Windows 與 Web。執行需要對應平台的原生擴充；缺少時請依 [建置說明](native/README.md)準備。

1. 準備期內選取卡牌，旋轉並放置防禦塔與道路。
   每個入口常駐顯示上方置中的「開始下一波」與下方橫排敵軍圖示，表示該入口實際出發的兵種；hover 某個圖示會拓寬邊框，顯示該兵種的個體數，例如「圖示 ×10」。道路上的米白短筆觸沿直段與圓角滑行，呈現方向與相對流量；hover 圖示只看該入口該兵種，移至標題或空白處顯示該入口全兵種，離開整組提示恢復所有入口。圖示太多可水平捲動；點圖示暫停並在進度頁查看該敵人，開波後預測自動隱藏。
2. 準備好後點任一入口上方的「開始下一波」文字開波；沒有倒數或開波額外獎勵。
3. 戰鬥期間觀察敵人的路線與火力效果；手牌收起，停止建造與交易。
4. 波次完成後使用右下商店補充卡牌，準備下一波；第 3／6／9／12 波後各選一次遺物。頂列遺物圖示列可 hover 查看效果、點擊開啟詳情。
5. 同種塔牌拖到已建塔可升級至 Lv.3，消耗卡牌但不額外扣金幣，也不新增道路。「成為主角」可解除哨塔上限。迫擊砲現在落地才造成傷害，高速敵人可能避開。

主畫面、選圖與遊戲之間以約 0.5 秒的白色淡入淡出銜接。暫停選單可「回到主畫面」，結束目前關卡；再次開始會建立全新進度。

| 操作 | 功能 |
| --- | --- |
| 點擊卡牌／1–9 | 選牌，再選同一張可取消 |
| 左鍵 | 放置選中的建造卡 |

| 右鍵拖曳 | 繞畫面中心畫圓旋轉地圖，角速度平滑跟隨滑鼠，放開後平滑減速停止；暫停時也可使用 |

一般商店目前恢復為四張防禦塔，單排右端保留重刷牌；臨時設施暫不販售，資源與獨立測試工具保留。旗幟吸引地面敵軍，拒馬讓小型地面敵軍迴避，窄口讓大型敵軍迴避；這些設施改變選路比例，並在參與三個完整波次後消失。選牌移到合法位置時，道路先顯示放置後的下一波預測，岔路的 ↑／↓ 表示實際配額增減；沒有實際分流變化時會顯示提示。Hover 已建設施可查看剩餘波數。

獨立人工驗收：F6 執行 `tests/traffic/playground.tscn`，提供三種輔助牌、100 金幣與雙入口環路；詳見 [Phase 2 驗收操作](tests/traffic/README.md)。

Phase 3 人工驗收：F6 執行 `tests/relics/playground.tscn`，提供六塔、同種手牌、逐件遺物選擇及快捷操作，見 [驗收步驟](tests/relics/README.md)。

鼠群、盾衛兵、血法師、飛翼獸、偵查兵與爆破手均已編入 Frontier，可透過分流嘗試拆散嘲諷、治療與癱瘓協同；硬性選路及配額有時會限制設施效果。首次實際出現的敵人會留下側邊未讀通知，點擊後才暫停並依序閱讀；暫停選單的「敵軍圖鑑」可重開已解鎖情報，跨局保留。下一波兵種圖示可開啟進度頁，主畫面與暫停選單的「進度」提供塔、敵人及遺物資料；未遭遇敵人保持問號。F6 執行 `tests/synergy/playground.tscn` 可玩四組獨立測試波次，見 [Phase 4 驗收操作](tests/synergy/README.md)。完整長局與證據見 [Phase 5](docs/phase5.md)、[數值與限制](docs/balance/phase5_final.md)，真人測試入口見 [遊玩驗收表](docs/balance/phase5_human_playtest.md)。

## 修改內容與開發

Routing Sandbox 的商店與初始手牌現包含哨塔、迫擊砲、弩砲、空艇舷炮、交叉火力與兵營，沿用新版等權塔種抽取。舊塔的獨立地塊、行為及原型來源見 [防禦塔資料](assets/data/towers/README.md)。可 F6 執行 `tests/combat/tower_restoration_playground.tscn`，在獨立關卡驗收六塔與雙入口，不改 Frontier。

道路與起終點可在 Godot 場景編輯，關卡、兵種、塔與地塊配置使用可編輯的資源。Godot 底部的「波次編輯器」可新增／刪除 ACT 與波次、調整出生群組，並以 checkbox 設定各 ACT 結束後是否新增出生點（預設勾選）；支援復原／重做與儲存。
