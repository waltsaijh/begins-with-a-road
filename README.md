# Begins With a Road

一款從雲海上的一條道路開始，透過卡牌逐步擴建戰場的 3D 塔防遊戲。每張建造卡同時帶來防禦塔與道路配置；你安排的不只是火力，也是在改變敵人接下來可以走的路。

## 核心遊戲體驗

地圖選單會自動收錄 `assets/data/levels/` 內的關卡；前置關卡全部通關後解鎖，通關紀錄會保留至下次啟動。製作新關卡只需新增 Level `.tres` 並指定地形與波次，選單預覽會自動載入；欄位與前置 ID 範例見[關卡說明](assets/data/levels/README.md)。

從簡單的橋面出發，挑選手牌、旋轉配置，把道路與防禦塔一起接進現有地圖。道路必須保持入口到終點暢通，因此每次建造都要考慮空間、繞路與火力覆蓋，不能靠完全封路阻止敵人。

不同兵種對道路有不同偏好：步兵在候選路線間平均分配，快腳兵傾向避開威脅，重裝兵則偏好高威脅路線。同一張地圖可能因此出現不同的進攻路徑；建造的價值也取決於下一波會遇到誰。

準備與戰鬥交替進行。你可以不限時安排防線，準備好後手動開始下一波。波次結束後，在商店購買或重刷建造卡，繼續延伸道路。前四個 ACT 完成後各三選一取得本局遺物；第五個 ACT 清完則勝利。Frontier 保留原入口，新增道路仍可改變敵人的分流與火力覆蓋。
自訂關卡可依各 ACT 設定，在遺物後選擴張方向與新增入口。

## 遊戲目標與目前進度

玩家的目標是利用有限的卡牌、空間與金幣建立防線，阻止敵人抵達終點，應對關卡各個 ACT 的進攻。設計重點是讓「鋪路」與「建塔」成為同一個決策，並讓不同兵種、道路形狀與本局遺物持續改變配置的取捨。

目前可遊玩五個 ACT、每個三波的完整首輪原型，包含建造／疊塔、商店、九種普通敵人、四次遺物選擇與最終攻城巨獸。防線有 20 點生命；一般漏敵扣 1，巨獸抵達即敗北，清完第 15 波及在途攻擊則勝利。結果畫面可重新開始。初始三張塔牌與 9 金幣，第一波前即可購買；每波不限時準備，擊殺不額外給錢。Frontier 不自動增加入口，獨立測試仍保留擴張工具。這是第一輪量測過的數值，尚待真人遊玩驗收，僅保存通關紀錄，沒有進行中存檔或局外成長。

## 開始遊玩

使用 Godot 4.7.2 開啟 `project.godot`，按 **F5** 先顯示共用顯示準備畫面，完成後開啟開始選單，點「開始遊戲」選擇戰場，按「下一步」進入同頁的本局設定，再按「開始作戰」進入正式關卡；也能先開設定調整語言、抗鋸齒與靜音。選圖頁目前提供「邊境前哨」，可預覽實際道路與入口、終點配置。本局設定先提供難度、起始手牌與額外事件的暫定選項，目前僅供流程預覽，尚未影響戰局；返回或 Esc 可逐步回上一步並保留選擇。專案使用 Compatibility 渲染器，目標包含 Windows 與 Web。執行需要對應平台的原生擴充；缺少時請依 [建置說明](native/README.md)準備。

1. 準備期內選取卡牌，旋轉並放置防禦塔與道路。
   Routing Sandbox 在每個入口顯示菱形驚嘆號，hover 展開「開始下一波」及該入口實際分配的下一波敵軍，並在道路顯示沿直段與圓角滑行的米白短筆觸；將游標移到兵種上可只看該入口該兵種的方向與相對流量，移至按鈕標題或空白處顯示該入口全兵種，離開整個按鈕恢復所有入口。超過三列可在按鈕內垂直捲動，開波後預測自動隱藏。
2. 準備好後點入口菱形或展開的「開始下一波」開波；沒有倒數或開波額外獎勵。
3. 戰鬥期間觀察敵人的路線與火力效果；手牌收起，停止建造與交易。
4. 波次完成後使用右下商店補充卡牌，準備下一波；第 3／6／9／12 波後各選一次遺物。左上「本局遺物」可查看已取得的效果。
5. 同種塔牌拖到已建塔可升級至 Lv.3，消耗卡牌但不額外扣金幣，也不新增道路。「成為主角」可解除哨塔上限。迫擊砲現在落地才造成傷害，高速敵人可能避開。

主畫面、選圖與遊戲之間以約 0.5 秒的白色淡入淡出銜接。暫停選單可「回到主畫面」，結束目前關卡；再次開始會建立全新進度。

| 操作 | 功能 |
| --- | --- |
| 點擊卡牌／1–9 | 選牌，再選同一張可取消 |
| 左鍵 | 放置選中的建造卡 |
| 按住手牌拖到地圖後放開 | 預覽並放置建造卡，無效位置保留卡片 |
| R／右鍵 | 選牌時順時針旋轉 |
| Esc | 取消選牌或收回商店；暫停時繼續遊戲；設定頁面中返回暫停選單 |
| 左鍵拖曳（卡牌以外） | 繞畫面中心畫圓旋轉地圖，角速度平滑跟隨滑鼠，放開後平滑減速停止；暫停時也可使用 |
| 中鍵拖曳／滾輪 | 平移／縮放鏡頭，暫停時也可使用 |
| 頂部倍速／暫停按鈕 | 切換 1x、2x、4x 或立即暫停 |
| 暫停 → 設定 | 分類調整語言、抗鋸齒與靜音；立即生效，目前不跨次啟動保存 |
| 暫停 → 回到主畫面 | 結束目前關卡並返回開始選單 |
| 右下牌組 | 波次結束後開啟商店；點商品購買、點右下牌重刷兩排 |
| F1／F2 | 開發用：查看本波兵種路線／地塊威脅與參數 |

商店現為上排四張防禦塔、下排兩張臨時設施。旗幟吸引地面敵軍，拒馬讓小型地面敵軍迴避，窄口讓大型敵軍迴避；這些設施改變選路比例，並在參與三個完整波次後消失。選牌移到合法位置時，道路先顯示放置後的下一波預測，岔路的 ↑／↓ 表示實際配額增減；沒有實際分流變化時會顯示提示。Hover 已建設施可查看剩餘波數。

獨立人工驗收：F6 執行 `tests/traffic/playground.tscn`，提供三種輔助牌、100 金幣與雙入口環路；詳見 [Phase 2 驗收操作](tests/traffic/README.md)。

Phase 3 人工驗收：F6 執行 `tests/relics/playground.tscn`，提供六塔、同種手牌、逐件遺物選擇及快捷操作，見 [驗收步驟](tests/relics/README.md)。

鼠群、盾衛兵、血法師、飛翼獸、偵查兵與爆破手均已編入 Frontier，可透過分流嘗試拆散嘲諷、治療與癱瘓協同；硬性選路及配額有時會限制設施效果。下一波兵種列的 **?** 可查看能力與選路習性，左側「敵軍情報」可重開。F6 執行 `tests/synergy/playground.tscn` 可玩四組獨立測試波次，見 [Phase 4 驗收操作](tests/synergy/README.md)。完整長局與證據見 [Phase 5](docs/phase5.md)、[數值與限制](docs/balance/phase5_final.md)，真人測試入口見 [遊玩驗收表](docs/balance/phase5_human_playtest.md)。

## 修改內容與開發

Routing Sandbox 的商店與初始手牌現包含哨塔、迫擊砲、弩砲、空艇舷炮、交叉火力與兵營，沿用新版等權塔種抽取。舊塔的獨立地塊、行為及原型來源見 [防禦塔資料](assets/data/towers/README.md)。可 F6 執行 `tests/combat/tower_restoration_playground.tscn`，在獨立關卡驗收六塔與雙入口，不改 Frontier。

道路與起終點可在 Godot 場景編輯，關卡、兵種、塔與地塊配置使用可編輯的資源。Godot 底部的「波次編輯器」可新增／刪除 ACT 與波次、調整出生群組，並以 checkbox 設定各 ACT 結束後是否新增出生點（預設勾選）；支援復原／重做與儲存。
