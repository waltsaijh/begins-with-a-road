# 專案結構

本文件提供目錄與系統層級的導覽。遊戲體驗與目標見 [README](../README.md)，開發共識與維護規則見 [AGENTS](../AGENTS.md)，實作細節見 [系統說明](systems.md)。

## 目錄分工

| 目錄 | 用途 |
| --- | --- |
| `assets/` | 可編輯的遊戲資料、模型、圖片、材質、字型與翻譯；`data/` 分為關卡、兵種、塔與地塊配置 |
| `scenes/` | 遊戲入口及依功能分類的場景；各分類的 `components/` 保存共用範本 |
| `scripts/` | 依功能分類的遊戲規則、流程協調與畫面控制 |
| `native/` | C++ 道路圖、局部搜尋、路線池與編輯檢查核心；`godot-cpp/` 是固定版本 SDK |
| `addons/` | Godot 編輯器工具，目前包含波次編輯器 |
| `tests/` | 依功能分類的 Godot／C++ 測試，以及共用測試資料 |
| `tools/` | 原生建置、離線素材產生、Web 服務與效能彙整工具 |
| `reports/` | 依功能分類的歷史驗證結果、量測與截圖 |
| `docs/` | 架構導覽與詳細系統說明 |
| `bin/` | 遊戲執行需要的原生擴充建置產物 |
| `build/`、`.godot/` | 匯出成品與本機快取，不是遊戲設定來源 |

## 遊戲系統

| 功能 | 責任 |
| --- | --- |
| 關卡 `levels` | 載入地形與端點、ACT／波次排程、入口擴張、時間線與暫停 |
| 卡牌 `cards` | 建造卡組合、手牌、旋轉預覽、放置意圖與商店交易；顯示與交易分開管理 |
| 地圖 `map` | 格子資料、道路接口與批次變更；外觀變種和浮起動畫獨立管理 |
| 導航 `navigation` | 道路快照、原生介接、兵種評分、有限候選池、路線配額與除錯顯示 |
| 敵人 `enemies` | 兵種設定、出生、固定行程移動；模型、避讓及頭頂狀態由顯示層處理 |
| 塔與戰鬥 `towers`／`combat` | 塔種、占格、威脅、索敵、攻擊、命中與效果 |
| 鏡頭與環境 `camera`／`environment` | 鏡頭平移縮放、雲海與環境呈現 |

## 資料與責任邊界

遊戲設定由 `assets/data/` 的 Resource 提供，場景組合可編輯的節點與外觀，GDScript 協調規則與流程。C++ 處理道路幾何與搜尋，不持有商店、關卡進度或敵人流量。血量、位置、冷卻與固定行程等即時狀態由各遊戲實體保存，不寫回共用設定。

建造流程由卡牌送出意圖，放置系統驗證整組道路與塔占格後提交地圖，再通知導航與顯示更新。預覽只讀候選資料，實際放置會再次驗證。導航從道路快照建立共用入口圖，再依兵種與起點建立候選路線及配額；開波時固定敵人的完整行程，移動期間不重新選路。

地形、戰鬥與行程是邏輯資料；地塊浮起、敵人避讓、特效及 UI 是呈現。動畫不能延後地圖提交，也不能改寫路線或命中結果。編輯器外掛、離線工具與歷史報告不參與正式遊戲執行。

## 開發支援

測試與報告使用相同功能分類，方便從系統找到相關驗證。素材工具產生可編輯的遊戲資產，原生工具將 C++ 核心建置到 `bin/`。正式匯出排除測試、工具、報告、技術文件與原生 SDK。

更細的操作入口見 [場景導覽](../scenes/README.md)、[測試說明](../tests/README.md)、[工具說明](../tools/README.md)與 [原生核心](../native/README.md)。
