## Implementation and test failures retained

- The first boss-model import attempted to load generated temporary scripts before their FileAccess handles closed. Close-before-load fixed the builder; the successful baked scene has no runtime legacy paths. The first import log is not a valid model acceptance result.
- An early PowerShell argument expression launched the wrong scene. Those logs were excluded. Awaited scene paths, matrix completion markers and independent sample counts now define completion.
- An early counterfactual identifier formatted Boolean values as `%d`, overwriting filenames despite an apparent 28-case completion print. The corrected run converts to integers and independently verifies 28 distinct files. The broken directory is excluded, not counted as evidence.
- Existing regression fixtures assumed nine waves, an always-open terminal shop, original damage constants, or manually stepped combat with an automatically processing stale spatial index. Tests now assert the new terminal behavior, freeze canonical relic-mechanism damage where the exact mechanism formula is the subject, and stop both ability/Barracks passes in manually driven fixtures. No production route or relic mechanism was weakened to satisfy old numeric assertions.
- Initial rendered QA showed integrity overlapping the relic inventory button. The label moved below both left-side controls; final screenshots and real restart tests verify the layout.
- The long candidate1 seven-policy pilot was stopped during its route policy once the actual 3-Gold configuration was rejected; only completed individual pilot runs enter selected evidence. It is not claimed as a completed seven-policy matrix.
- Replaying the original tower matrix after spawn RNG separation changed five of 72 applied-damage outcomes, all Mortar cases. Restoring the original global stream at seed11 reproduced all 72 on damage, kills, leaks, overkill and healing. Both replays are retained, with a machine-checked comparison. Cross-era Mortar deltas are therefore not perfectly paired; final Lv.1 versus Lv.3 and encounter factorials use matched streams.
- Only Swarm/23 among the fourteen final training runs used a paid reroll (one Gold). An additional seed23 Generalist probe bought one reroll in each of fifteen preparations: victory, three leaks and four Gold, versus four leaks and zero Gold without forced rerolls. Different offers, relics and friendly-fire losses compound; one observation does not show that rerolling is either useless or dominant.

## Final evaluation interpretation

Training, holdout and one-variable sensitivities are reported separately in `phase5_final.md`. The final candidate was frozen before the reserved seeds/maps ran. Local failures under HP/speed/price changes are evidence of limited margin, not reasons to redefine the holdouts. Small sample sizes do not support population win rates or confidence intervals. Raw result distributions and any unresolved expensive Route Manager preparation are retained for future profiling; no headless timing is advertised as game FPS.
