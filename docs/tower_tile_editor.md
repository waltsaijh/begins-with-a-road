# Tower Tile Editor

獨立的 Godot 場景工具。可自由畫出同一種塔的不同連通塔體與道路，儲存為原生 TilePreset，立即補入手牌、按原規則一張一張放置，再以正式戰鬥系統試玩。沒有批次確認，也沒有啟用 Construction Prototype 的幾何加成。

## 開啟

- 編輯入口：開啟 `tests/tower_tile_editor/editor.tscn`，按 **F6**。
- 直接試玩：開啟 `tests/tower_tile_editor/playground.tscn`，按 **F6**；準備期按右上「開啟地塊編輯器」。
- **F5 仍是 Frontier**，正式候選已引用保存的「基礎版」20＋1 組合；其他測試組合與補助仍僅限 Playground。

目前這台 Windows 曾封鎖 Godot Editor 複製的 `~road_graph…dll`。這次驗證的是以下直接執行入口，未改系統安全設定，也未宣稱解除 Editor 的 DLL 封鎖：

```powershell
& C:\tools\Godot.exe --path D:\games\begins-with-a-road-routing res://tests/tower_tile_editor/editor.tscn
```

工具仍在 Godot 內執行，不需要外部網站或另一套應用程式。Windows 載入問題背景見 [native/README](../native/README.md#windows-編輯器載入封鎖2026-10-25)。

## 從空白配置開始

1. 左側選六種現有塔之一，按「新配置」。也可選既有配置後「複製為獨立配置」；內建檔不會被覆寫。
2. 中央選「塔體筆刷」，左鍵點格或拖曳。藍綠格全部是實際障礙；可畫 1×3、2×2、L、T、十字或其他四向連通形狀。快速跨格拖曳會補齊中間格。
3. 選「道路筆刷」畫金色道路。繪製塔體會清除該格道路，繪製道路也會清除該格塔體；橡皮擦清空兩者。道路完全由你繪製，不會自動包成一圈。
4. 「塔錨點」設置塔的邏輯識別與朝向參考，白圓必須在塔體內；「放置原點」把點選格移到白十字 `(0,0)`，同時平移所有格子、錨點及自訂駐點。
5. 右側設定名稱、權重、塔朝向、允許旋轉、卡牌預設旋轉。模型 X/Y/Z 是塔自身朝向下的**視覺位移**；多格塔攻擊範圍、威脅與砲口依實際塔體中心／主軸，白圓仍是塔的識別錨點，模型位移不改幾何中心。普通配置保留零位移即可。
6. 按「儲存並套用候選」，或「儲存 → 加入手牌試玩」。後者立刻返回同一局並補一張所選塔＋配置，不重啟 Godot。

網格可切換 9、11、15、21 格。切換大小只改工作區，不裁掉資料；縮小後看不到的格子仍保留，請切回較大網格編輯。旋轉預覽只改觀看角度，筆刷座標自動轉回原始配置。Undo／Redo 支援格子、接口、原點、錨點、名稱、方向與模型位移；快捷鍵 Ctrl+Z／Ctrl+Y，Ctrl+S 儲存。切換塔、配置或返回關卡前，未存修改會要求確認捨棄。

右側顯示占地尺寸、塔格／道路格數、ID、所屬塔與驗證結果。無效配置以紅框提示，允許暫存於工作中的草稿，但不能儲存。至少要有一格塔體、塔體四向連通、錨點在體內、道路不重疊、接口相符，且預設方向必須在允許清單中。地圖端的入口／終點、石地、其他占位、兵營駐點、固定行程和道路連通仍在每次放置時另行檢查。

## 道路接口與兵營

未勾選「手動接口」時，道路按相鄰格自動相接。勾選後每格保存北／東／南／西 `1/2/4/8`，用四個勾選框組成筆刷，選「接口筆刷」點道路。內部相鄰接口會同步調整對側，避免單向矛盾。朝空白的許可接口以短虛線顯示；實線只代表相鄰道路間的雙向接口。未連到完整路線的延伸端不會產生敵軍流量。

同格道路可合併接口；相鄰道路仍須雙方同意才連通。旋轉會同步旋轉格子及接口位元。切回自動模式會清除手動遮罩，可用復原撤回。

兵營另有「使用指定兵營駐點」及「兵營駐點」筆刷，綠圈表示駐點。兵營錨點仍需覆蓋既有道路；自訂駐點可以在附帶道路上，但不能在塔體、端點或其他占位內，且必須能通往有效路網。未指定時沿用原本前方一格。其他塔不需要設定此項。

## 配置管理與抽取

使用者配置由工具第一次儲存時建立於：

```text
assets/data/tower_tiles/user/
  catalog.tres             塔種類、配置 ID、檔案引用、權重、預設與封存狀態
  user_<隨機穩定ID>.tres   TilePreset 幾何與名稱
```

儲存使用暫存檔替換，索引寫入失敗時還原配置檔。複製產生新 ID，改名不改 ID。按「重新載入磁碟配置」可確認保存內容；再次開啟場景也會讀取同一個索引。

未限制組合時，自建候選和原有內建候選一起進入 Playground 的**實際商店權重抽取**；可用下述選項排除內建或指定配置白名單。權重 0 不抽取，但組合內仍可手動補牌。權重是每種塔內部的配置權重，不改塔種洗牌袋、價格或戰鬥資料。儲存配置立即更新後續抽取；已顯示商品保留原結果，可用商店重刷或「依候選權重重抽 6 張」。星號預設只控制選單，不提高機率。

「移出候選」經確認後從清單及後續抽取移除自建配置，**保留原 `.tres`**，避免其他場景或資源引用失聯；不會刪除已持有卡牌或地圖上的塔。這是有意的安全封存，非永久刪檔。內建配置不能移除。手牌及已建塔保存幾何快照，後續編輯同一份配置只影響新卡。

## 內建篩選與具名組合（2026-10-26）

左側「內建不參與測試」排除所有內建配置的抽取、補牌與放置；「隱藏內建配置」只摺疊清單，不改抽取資格。兩項獨立保存，可隨時取消。使用自建配置不需要修改原 TowerDefinition 或把所有內建權重逐一設成零。

按「管理／儲存測試組合…」，跨塔種勾選需要的配置並命名，例如「長塔＋兵營」。可清空勾選後重新選，按「儲存並套用組合」更新目前組合，或「另存為新組合並套用」保留另一份比較。組合記錄於 catalog.tres，保存穩定 ID、名稱、塔種＋配置 ID 成員及排除內建選項；目前啟用的組合也會保存。組合共用各配置的最新幾何與權重，並不複製版本；要比較修改前後的形狀，先複製配置。

回到試玩後，右上「測試組合（切換會重開）」可快速切換。套用組合或改變內建參與規則會重開獨立測試關卡，清除上組的塔、手牌、商品及波次，重新套用該組抽取池；在編輯器內設定時，於返回試玩時重開。只有組合內的塔＋配置能抽取、補牌、放置或作為升級卡；直接放置 API 也會檢查。空組合維持無塔可抽，不回退內建。輔助交通設施不屬於防禦塔組合，保留原商店池。

「全部可用配置」取消成員白名單，仍遵守「內建不參與測試」。新存的配置不會偷偷加入既有組合；需在組合視窗勾選後才能補牌。已封存／遺失的成員不參與抽取及放置。隱藏內建只為減少清單干擾，不代表已排除它們。

## 即時測試關卡

初始為 17 格直路、60 Gold、無敗北、空手牌。補入指定配置或依候選重抽 6 張都是明示的免費測試補助；原商店購買仍照價扣錢。可以把同一塔種類的兩份配置同時放在手牌。

- 點牌後點地圖，或直接拖牌到地圖。R／右鍵旋轉；成功立即提交一座塔、消耗一張牌。失敗顯示原因，不耗牌或金幣。
- 預覽沒有道路接口線；淡金攻擊範圍為無格線的連續色面。預覽中金色為新增道路、淡青為重疊道路、青色為塔體，橙紅色塔格表示將阻擋原有道路；外框綠／紅表示合法性。米白流動筆觸顯示**放置後**的下一波完整行程，旁邊標示「未提交」。預測只在換格、旋轉或資料失效時重算，不寫入路線歷史、不消耗商店／出兵 RNG。
- 五塔改用依占格展開的完整低面數模型，預覽與實體共用；Lv1–3 有獨立加件。全部格子仍回查同一座塔、同一血量與等級。把目前組合允許的同種類卡放到任一占格可升級，忽略新卡的道路／塔體形狀。多格射程中心、側舷兩側各 2×3 與弩砲主軸同步調整；不新增射線遮擋。詳見 [塔體／射程／預覽](tower_visuals_and_preview.md)。
- 點入口菱形手動開波，沿用 1.5 秒開場、真實 Soldier／Scout／Winged 混兵、索敵、彈道、漏敵與獎勵。共六波；戰鬥期間禁止編輯與補牌。
- 原鏡頭中鍵平移、滾輪縮放與左鍵環繞保留。F1 可查看行程，F2 看地塊資料。進入編輯器時凍結世界並停用關卡輸入，離開時恢復，畫筆不會被鏡頭截走。
- 「重開直線關卡」清除塔、手牌、敵人及進度，回到 60 Gold、1x；已儲存的配置保留。

## 人工驗收 A–E

| 情境 | 操作與觀察 |
|---|---|
| A 長船體 | Broadside 畫 `(-1,0),(0,0),(1,0)`；道路畫 `x=-2…2,y=-1`，兩端接 `(-2,0),(2,0)`。塔朝向 270°，放到直路中央。三格皆阻擋，敵人經單側繞道；保持原左右側舷射擊語意。 |
| B 不完整道路 | Mortar 一格塔體、左右各一格道路。放到直路旁可成功，只有三格地塊；放到唯一通道中央應拒絕，不能自動補成環。 |
| C 十字塔 | Crossfire 畫中心及四鄰五格，外圍只畫上方繞路。旋轉後放置，確認仍是一座塔、五格障礙，範圍依整體塔體中心；白圓仍是塔的邏輯錨點。 |
| D 同塔多配置 | 複製 Broadside，改成另一連通形狀並儲存；分別補牌、旋轉、放置。兩者沿用同一種塔與戰鬥數值，各自有不同的實際占位。 |
| E 持久化 | 改名、設權重與預設、編輯手動接口後儲存，再重新載入或重開場景，確認 ID、塔、格子、遮罩、方向及權重一致。移出候選後舊引用仍可讀。 |
