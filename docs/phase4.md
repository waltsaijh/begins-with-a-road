## 選路責任與身份

原 `RoadPortalGraph` 的節點、壓縮道路編號與候選索引會隨幾何重建改變；有限池也會依搜尋預算、成本及代表路線取樣改變。它們不能表示「一條完整通行選擇首次成立」。因此 `PortalMap` 仍管理同一份路網，但在已提交的可通行格／雙向接口與端點上保存 `RouteHistory`，不從 preview、候選序號或重新搜尋產生出生時間。

每份歷史快照保存世界格座標、接口、起點／終點及 wave。第一份為 wave 0，後續準備期使用即將開始的全局波次編號。完全相同的幾何重建不新增歷史。完整有向格序列是路線身份；其出生波次為歷史中首次同時包含全部路段及相同端點的快照。刪除後恢復同一完整路線仍保留首次出生時間；單純接上死路不會改變舊路身份。

原生 `RoadSpecialRoutes` 使用與原導航相同的合法道路接口，獨立生成硬性資格所需代表路線，避免普通 Cost 池漏掉新路或最短路：

- **SHORTEST**：從兩端 BFS 得到真實格距；只在最短路 DAG 中組合完整路線，每條合格有向邊保留一個代表並依完整序列去重。不是以 Cost Score 近似距離。
- **NEWEST，歷史單調增建**：對每條現存無向邊，用兩單位頂點容量 flow 找到經過該邊的簡單入口至終點路線。這會排除死路及單點掛接的環。每條可行邊有代表，因此最新成立的完整選擇不會因普通搜尋預算而遺失。只保留最高出生波次；同波的不同新分支都可取得代表。
- **NEWEST，刪除／重接造成非單調歷史**：以最多 200,000 次展開的搜尋檢查路線與歷史是否曾同時成立。超限回報失敗，畫面顯示無法確認最新路線並禁止開波，不偷偷回退舊路。一般新路失效但能完成查證時，選取仍有效的最新批次。

上述代表集有限，不列出所有組合，也不宣稱對全圖所有同分簡單路徑均勻取樣。增建分支可用邊代表保障最新資格；複雜非單調地圖可能觸發明示的工作上限。歷史只存在於本局，重開重置，沒有加入存檔系統。

普通 COST 保留原有限候選池、評分、strict threshold、Uniform／Softmax。硬性規則不套普通 Cost cutoff／Search Budget，以等基礎分數建立分布，再沿用 `TrafficWeights`、`RouteDistribution` 及既有確定性配額。旗幟 ground ×1.5；拒馬改為 small＋ground ×0.5；窄口 large＋ground ×0.5。飛行兵種忽略地面設施。旗幟不能讓被最新資格排除的舊路重新入選。

## 鼠群與一致的預覽／正式出兵

`WaveSpawnSchedule` 先把每個 SpawnGroup 切成大小為 `cohort_size` 的群；尾群可不足 5 隻，不補生。群組邊界保留，因此 12 隻與 8 隻兩組會形成 3＋2 群。

入口分配先按整群完成；同兵種、同入口的跨群組路線配額，以群數作為 `index / total` 單位，整群取得同一完整路線，再展開為獨立敵人。每隻仍有獨立 ID、HP、移速、狀態與死亡。正式出發只打亂完整群的順序，尾群保持最後，不拆散跨入口或跨路線。

群體模式的時間為 `start_tick + 群序 × max(interval_ticks, cohort_size × cohort_interval_ticks) + 群內序 × cohort_interval_ticks`。每 tick 0.25 秒；群體模式取代一般 Batch Size 的並發生成。非群體兵種仍沿用原批次規則。

預覽使用不洗牌的同一份 schedule，按展開後的個體累加道路流量、入口／兵種數量，因此鼠群顯示隻數。正式開波複製路線、waypoints、HP、shield、速度及能力參數，之後的設施／地圖變更不改既有行程；預覽不消耗出發 shuffle RNG。獨立試驗的舊 EnemyWave 入口遇到群體兵種時，也使用同一排程。

## 戰鬥接入

`EnemyAbilities` 在敵人移動後建立共用格子索引，兵營與塔接續使用。能力時鐘屬於敵人實例，使用模擬時間，隨暫停／倍速控制；能力設定在開波時快照。

- **嘲諷**只對原攻擊規則已允許的候選排序，依優先級、平面距離、出生 ID 穩定選擇。不能突破攻擊格、射程、對空或特定遺物的合法目標條件。Sentry、單體 Volley、兵營及專屬單體效果共用規則；十字火力的 ALL 攻擊照常打全部目標。減傷在護盾／HP 扣除前計算。
- **治療**依自己的時鐘治療半徑內可存活友軍（包括自己），上限為各自 max_health，不復活。多名血法師獨立結算。治療成功時施法者顯示短暫綠圈；慢幀每次更新至多一次脈衝，避免積壓特效連發。
- **飛行**以固定道路 waypoints 加高度，不穿越無道路空地。Sentry、弩砲、十字火力、空艇舷炮可對空；兵營近戰不能攔截／傷害飛行，神射手遺物的遠程友軍可對空。普通迫擊砲的索敵和濺射都排除 flying；空中打擊才開啟資格及對空傷害。
- **癱瘓**先選半徑內最近合法塔，同距離以格座標穩定決定；前搖有橘圈、指向線與技能進度，目標消失／離開範圍即取消。命中後塔頂顯示閃電圖示，塔攻擊、專屬攻擊與兵營友軍暫停，已發射的投射物繼續。每個施法者持有一份剩餘時間，重複取最大值，多來源也取最大值，不累加秒數；來源死亡移除其效果，其他存活來源可繼續維持。波次結束清空，重開／卸載隨實例釋放。TowerDefinition、升級、道路及威脅資料不被改寫。

## 驗收與限制

可玩入口、A–D 操作及回歸命令見 [測試說明](../tests/synergy/README.md)，目前 HEAD、程式索引及各次驗證分界見 [HANDOFF](HANDOFF.md)。當次 JSON、截圖與驗收結果寫入 `.godot/test-results/synergy/`；不把舊測試結果當成本次證據。

需後續平衡：群體大小／間隔、盾衛減傷與嘲諷半徑、治療頻率與範圍、飛行速度、癱瘓冷卻／持續時間及多人接力效果。分流效果會受地形、有限代表與整數配額限制；測試場景有意提供可分支路網，不代表任何地圖都能同幅度分離。

新增原生類別需重啟 Godot editor。擴充輸出改為 `road_graph.editguard.phase4.*`，可與先前被 editor 載入的 DLL 共存；Windows debug／release 在 Phase 4 開發階段已建置，Offboarding 本次只核對現有產物及 debug 載入、未重建。維持 C++17、Compatibility 與單執行緒 Web 設計；Phase 4 的 Web wasm 建置及瀏覽器尚未驗證，不能將 Windows PASS 當成 Web PASS。
