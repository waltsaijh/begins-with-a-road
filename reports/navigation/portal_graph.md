# 入口圖驗證（2026-10-15）

本檔記錄入口圖基礎版本的驗證與量測。後續已新增區塊內全部等長最短路，最新資料與驗證見 `portal_paths.md`；下文時間不包含後續新增的局部最短路計算。

舊覆蓋路線、舊拓撲塌縮、分類器、控制器、顯示器、測試、報告與舊 Web 匯出均已移除。目前只使用新的 RoadPortalGraph 與入口顯示，沒有 ZDD、flow field 或完整路線生成。保留通用 godot-cpp SDK／編譯工具，以及原有美術、地圖、起終點與操作。

## 結果

圖片對應案例：5×3 寬區、左側道路、右上外接道路、下側繞行道路及右側匯合點。得到一個寬區、三個入口、右側一個真正交會點、兩端起終點，共 6 個可見節點與 4 條外部道路。三個入口在寬區邊緣，中央沒有節點。以不畫在地圖上的 region incidence relation 表示三個入口互通，不建立假的三角環。

11×11 無障礙寬區加左右各三格外接道路：1 寬區／4 可見節點（兩個入口及起終點）／2 外部道路，只有一種區段穿越選項。區域內有 3×5 障礙時，掃描拆為 4 個無洞區段，保留兩側選擇與一個真實獨立環。無洞的階梯／T 形寬區仍合成一區，不切成一堆矩形。

## 實作

- 固定四鄰接、packed 整數座標與接口遮罩；native 端計算雙向連接。
- 2×2 填滿面共用邊時以 DSU 分組；角點相接保留 gate。
- 面群無洞時直接合併，有洞時沿較長方向掃描，在分開／匯合事件切分，連續 1 對 1 區間保持同區。
- 開口保留完整 window；圖上的節點只是代表點。外部 degree-2 路段壓成 edge，保留平行道路與細環。
- 內部邏輯使用無座標的 region incidence vertex；資料量隨入口數線性增加，不建立區域內 P² 的連線。
- 每次建立新快照，同幀修改合併一次。無遞迴搜尋、不列舉所有 simple paths。
- 淡色與細框顯示寬區，青色實線顯示外部道路。粉色為入口、黃為外部岔點，Tab 選區段／道路，G 隱藏圖，L 隱藏編號。固定兩個 mesh，文字上限 96 個。

區域框線只表示範圍，不是獨立路線；入口代表點不是角色必經位置。目前未評估區域內成本，也沒有禁止區段重訪或建立路線決策樹。節點與區段 ID 僅對當前快照有效。

## 正確性

`tests/native/portal_graph.cpp`：圖片案例、入口位置、寬區合併、障礙兩側、單格接觸、共享 window 上的起終點、外部 T 分支、純細環、孤島、不對稱接口、負座標、重複座標、9×9 交會點迷宮與 50×50 全滿。多入口寬區驗證入口資料不展開為 clique。

3000 張固定 seed 的隨機 9×9 地圖，以獨立的背景 flood-fill 比對洞數，並核對輸出的分量與 cycle rank；檢查每條代表線不重複地塊、相鄰、接口相接，兩端位於節點位置。全部通過。這些測試驗證表示結構，沒有聲稱保存原始格子圖的全部 simple paths。

`tests/navigation/portal_graph.gd`：native 綁定、packed snapshot、依圖片對應的三個入口位置、中央無岔點、障礙拆分、放置後更新、同幀合併、2×2 換道、孤島、兩個 mesh、Tab／G／L、原有自訂地圖及輸入錯誤。原有 `tests/maps/tile_placement.gd` 也通過。

原始兩份場景的 GridMap data 與起終點 transform 比對保留，只更換分析與顯示節點。

## Windows 核心效能

MSVC 14.44.35207，x64，C++17，/O2。暖機一次，20 次完整核心建構取中位數，包含座標索引、分量、分區、入口與走廊，未包含 GDScript 快照、Variant 封裝、mesh 與文字。只在 Windows 量測。

| 場景 | 中位數 | 可見節點 | 寬區 | 外部道路 |
| --- | ---: | ---: | ---: | ---: |
| 11×11 全滿＋左右外接道路 | 0.0419 ms | 4 | 1 | 2 |
| 9×9 交會點、17×17 地塊迷宮 | 0.1098 ms | 79 | 0 | 142 |
| 50×50 全滿、起終點在左右邊界 | 1.1344 ms | 2 | 1 | 0 |

這是固定案例本機時間，不是所有地圖的上限。主要排序 O(N log N)，其餘為索引、DSU、掃描與走廊追蹤，空間隨輸入與輸出大小增加；建圖及顯示同步執行。

## Web 與清理

Windows／Web debug、release 均建置；Web 維持 Compatibility、WebGL 2.0、單執行緒。瀏覽器驗證記錄於 portal_web.json，圖片對應案例為 portal_preview.png，寬區內障礙案例為 portal_obstacle_preview.png。比對圖片案例的節點位置、區段成員、入口關係與外部代表線，Web 與 Windows release 一致。Web 未做速度比較。

舊原始碼、測試、報告、Web 匯出與舊 DLL 暫存已清除；bin 只剩新 road_graph 擴充及其編譯／編輯器暫存。兩份原始場景的 GridMap 與起終點資料保持不變。
