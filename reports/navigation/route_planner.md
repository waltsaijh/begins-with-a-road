# 共用入口圖與兵種 A*（2026-10-15）

此為入口 edge 評分版本的歷史紀錄。現版採逐 tile evaluation、雙向有環的有限候選池，請見 `diverse_routes.md` 與 `route_distribution.md`；下文 API 與時間不代表新版本。舊原始量測和預覽檔已於專案清理時移除。

依最新決定撤掉本次接入的 ZDD 原始碼、註冊與測試，改為 RoadRoutePlanner。所有兵種共用入口移動圖，依 profile 與連線成本快取 A* 結果。沒有敵人物件。

區塊內仍只保留幾何最短走法，所有等長走法完整保存；全域不列舉非最佳 simple paths。A* 搜尋保留所有等分最佳前驅，裁成最佳路線 DAG。抽樣時才選出完整節點與地塊序列。途中遇到其他已標記節點會拆開，沒有隱藏節點訪問；同一區塊可再次進入，但節點不重複。

## Windows 效能

使用當前磁碟上的兩個使用者場景，沒有替換成生成的方形測試圖。測量時 `9x9` 是 312 格／107 節點／194 條移動邊，`11x11big` 是 146 格／8 節點／10 條移動邊。測量場景檔案 SHA256 記錄在 route_benchmark.json；工作期間未改動地圖資料。

Godot 4.7.2，Windows x86_64 template_release 原生擴充，headless。暖機一次，20 次完整建立後取中位數；每輪重新建立規劃器，避免以快取冒充搜尋時間。抽樣每輪 100 次、共 2000 次／場景，表列各輪平均的中位數。

| 場景 | 快照＋入口／局部建圖 | 移動圖準備 | A* 查詢含封裝 | 完整重建合計 | 每隻抽定實際路線 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 9x9 | 1.975 ms | 1.143 ms | 0.069 ms | 3.273 ms | 0.00494 ms |
| 11x11big | 0.546 ms | 0.239 ms | 0.020 ms | 0.830 ms | 0.01719 ms |

合計中位數直接量測每輪總和，並非各欄中位數相加。最大單輪總計分別為 4.513 ms、1.344 ms。測量不含場景載入、模型刷新、繪圖或敵人生成；不是幀時間上限。

9x9 的 A* 展開 12 個節點，最佳路線 23 步；11x11big 展開 8 個節點，最佳路線 33 步。兩者目前都只有一種最佳節點序列，但 11x11big 的區塊內保留多種等長地塊走法，抽樣可取得不同走法。較長的節點路線不會因為有更多候選就增加 A* 的路線列舉成本。

原生常駐資料估算：9x9 共用移動圖約 34,708 bytes、每個 profile 約 2,760 bytes；11x11big 分別為 7,320 bytes、336 bytes。不包含 Godot 場景／Variant、原入口圖與局部距離表、配置器開銷、搜尋暫存或程序峰值。

## 驗證與操作

- C++：1024 張五節點無向圖，兩種成本設定，與獨立 DFS 的全部最短路線集合比較；平行邊、非法成本、無路線、等分抽樣及座標索引置換通過。
- Godot：兵種快取與成本更新失效、地圖更新清快取、局部兩條等長路線、完整實體路線連續且每個實際入口訪問均有記錄；兩個真實場景各 32 個種子通過。
- 原入口／局部最短路回歸測試通過。
- Windows／Web debug、release 已建置。兩個真實場景在 Web 的分數、最佳 DAG 與各 16 條完整抽樣路線和 Windows 完全一致；N／P／Esc／G 與正式主場景啟動通過，無瀏覽器錯誤。Web 僅驗證 Compatibility 與功能一致性，不量測效能。記錄見 route_web.json；預覽為 route_9x9_preview.png、route_11x11big_preview.png。

N 抽選並以綠線顯示完整最佳路線；P 檢查區塊內每對入口的全部最短走法；Esc 回總覽。原生擴充更新後需重新啟動 Godot。
