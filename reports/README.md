# 驗證報告與預覽

歷史結果與截圖按功能分類保存，檔名沿用原名；對應測試與工具也會寫入新位置。這些內容是驗證時的紀錄，遊戲目前的數值以 `assets/data/` 為準。

| 目錄 | 內容 |
| --- | --- |
| `cards/` | 卡牌、商店、手牌與旋轉提示 |
| `combat/` | 防禦塔、障礙物、攻擊與特效 |
| `enemies/` | 兵種、步態、血條、避讓及 MultiMesh |
| `levels/` | ACT 擴張、時間線、暫停與鏡頭 |
| `maps/` | 地塊外觀與浮起動畫 |
| `navigation/` | 入口圖、選路、配額、地塊成本及效能 |
| `assets/` | Blender 與模型原型預覽 |
| `project/` | 歷次專案結構與清理紀錄 |
| `performance/` | 跨平台極端負載、逐幀時間及系統成本 |

根目錄的 `.gdignore` 使 Godot 不匯入這些分析檔與圖片。報告未通過或程式仍在執行時，請先看測試輸出；舊截圖或 JSON 本身不代表目前版本已通過。
