# 波次商店與手牌

每波結束升起五張背面牌；點擊後展開四張商品與最左側重刷牌。開店疊起手牌並暫停建造，點外側空白處收回，下一波開始時隱藏。購買後卡片從畫面底部插入手牌，成功放置消耗，失敗保留；商品與價格立即隱藏，其餘商店牌向右靠攏。重刷的四張新牌也從底部插入。

既有手牌不重建，新卡僅新增一個卡面，消耗後快捷鍵與點擊索引同步更新。動畫從當前位置接續，可中斷收合，不會重新將卡丟回畫面外。一般畫面移除手牌狀態、操作提示、波次數字及除錯文字；保留卡面、價格、餘額與圖示按鈕。F1～F3 啟用後仍可查看除錯資料。

沒有 Dimmer、全螢幕攔截 Control 或商店標題面板。手牌與商店共用鏡像弧度布局：朝螢幕外側抬高、往內側下降，卡牌上端中心位於同一圓弧，旋轉取其切線角度。最大 4°、邊緣僅重疊 8 個原始像素，卡片縮為 82%。金色六邊形 PNG 用於各卡價格與餘額。

Hover 只沿卡牌自身上方提起 12 個原始像素，不放大、不置頂、不移動左右卡牌。CardButton 保留原位置下緣的點擊範圍，使提起後仍能從原下緣維持 hover 與點擊。動畫不參與重新選牌，只在實際滑鼠移動、狀態或視窗尺寸改變時更新布局。原卡面及圖片尺寸不變。

預設每波獲得 10 金幣，卡片 3、重刷 1；可在 card_shop.tscn／BuildCard Inspector 調整。牌背與圖示為 PNG，商品沿用既有卡面場景。介面使用 Tween，沒有逐幀更新或新增渲染器需求。

`tests/cards/card_shop.tscn` 驗證：

- 五張背面、四商品與重刷牌、全部價格、升起／翻面／快速反轉動畫。
- 購買扣款、加入手牌、售出防重購、金幣不足與重刷。
- 插牌起點在畫面下方、實際上移、既有手牌實例不變；消耗後剩餘卡面與點擊索引正確。
- 非相鄰商品買走後向右靠攏、沒有空洞、最右牌保持貼齊；靠攏後仍購買正確商品。
- 購買後等待收合／展開動畫完整結束，已售出牌槽仍隱藏，不會殘留牌背蓋住商品（`shop_reopened.png`）。
- 重刷四張新牌插入，插牌途中收回／重開也保留庫存與正確卡面。
- 開店手牌疊起、點價格不關店、點外側關店且不誤放地塊。
- 放置失敗保留、成功消耗；下一波隱藏商店。
- 全員抵達與全員擊殺皆開店，同一波的重複結束通知不重複發錢。
- 外側高於內側、角度小於 5°、縮小與邊緣交疊，旋轉後仍正確接收點擊。
- Hover 沿自身上方提起、尺寸與前後順序不變、相鄰牌保持原位，移開後復位。
- 停住游標不抖動，原下緣仍可選卡／購買，兩端／中間各牌的邊緣切換正確。
- 靜止時相鄰上緣在重疊範圍的高低差小於 1 px。
- 遊戲空白區不被 UI 攔截；售出卡及價格隱藏；餘額與價格共用金幣圖示。

Windows Compatibility 與單執行緒 Web 的結果在 `shop.json`；Web 以瀏覽器實際 GUI 事件驗證。另重跑既有卡片與除錯顯示測試。預覽為 `shop_closed.png`、`shop_open.png`、`shop_sold.png`、`shop_reroll.png`、`hand_purchase.png`、`shop_web.png`。

重測：Windows 執行 `tests/cards/card_shop.tscn`；測試 Web 匯出後執行 `node tools/web/verify_enemy_web.cjs --shop --cards`。只驗證商店可用 `--shop --only=shop`。一般正式匯出仍排除 tests。
